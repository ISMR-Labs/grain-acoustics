# Media

## photos/2026-10-10-sensor-node

Build and bench photos of the sensor node on the day the final wiring was completed:
ESP32 breakout with input networks, piezo disc in its pad, the printed controller box with four
cable glands, the pods and pads, and the node streaming to the dashboard. EXIF metadata removed,
long edge resized to 1600 px.

## photos/2026-09-24-vibration-array

An earlier build from the same lab, two weeks before the sensor node: a controller box with a
single push button driving 17 small vibration-motor modules with status LEDs over braided
leads, in printed enclosures (`vibration-motor-enclosure` and `controller-box` Forge projects).
It is included because it shares the enclosure design approach and the cabling, and because a
controllable vibration source is useful as a calibration stimulus for the piezo channels. Its
exact role in the rice study is still to be written up.
